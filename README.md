# LASTLINE — APK Builder

Ye repo apna HTML game **Android APK** mein convert karta hai — GitHub Actions se, bilkul free.

## APK banane ke liye
1. Isme upload ki hui files commit karo
2. **Actions** tab kholo → **Build APK** workflow khud chal jayega (ya "Run workflow" dabao)
3. 5–15 min mein green ✅ aayega
4. Us run ke andar neeche **Artifacts → LASTLINE-APK** → download → phone pe install

## Game update karna
Repo ke root wali **index.html** nayi file se replace karke commit karo →
build apne aap dobara chalega → naya APK naye artifact mein mil jayega.
